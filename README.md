# MiniProject
# 🖥️ PC Anatomy Engine

An interactive web application that visually explains the architecture of a computer motherboard and its hardware components. Users can explore different PC components, learn about their functions, and test their knowledge through an interactive quiz.

---

## 📌 Features

### 🎯 Interactive Motherboard
- Clickable motherboard components
- Detailed information panel
- Real-world hardware examples
- Troubleshooting tips
- Interesting facts

### 🔍 Smart Search
- Search any hardware component
- Matching components are highlighted instantly

### 📖 Guided Learning Mode
- Step-by-step walkthrough of every motherboard component
- Automatic zoom and focus on each component
- Previous and Next navigation

### 🎮 Quiz Mode
- Multiple-choice questions
- Instant answer validation
- Final score summary
- Retry quiz option

### 🔍 Zoom & Pan
- Mouse wheel zoom
- Drag to move around motherboard
- Reset view option

### 🌗 Dark / Light Theme
- Toggle between dark and light themes

### 🏷️ Component Labels
- Show or hide labels on the motherboard

### 💡 Tooltips
- Hover over components to view their names instantly
